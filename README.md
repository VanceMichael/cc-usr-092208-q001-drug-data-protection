# 药物试验数据保护期核定

核定儿童药和罕见病用药试验数据的保护范围与有效期限。核心要求：**一项后来申请究竟受理、暂缓还是等待保护期届满，必须能回到当时有效的法规、数据来源与签批记录，不能只看系统里最新的截止日期；任何历史决定都不得被后来状态覆盖。**

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例（全部成分、机构、批件均为虚构）。当前参与方包括药品申请人、审评人员、法规复核人员、数据权利持有人。

资料所依据的领域事实如下：

- 监管部门将推进药品试验数据保护制度落地
- 儿童药品和罕见病用药将建立市场独占期制度
- 制度目标之一是保障企业研发投入
- 同一活性成分会先后增加剂型、适应症与持有人
- 境内外试验数据存在授权引用、公开披露与补充提交之分

## 资料模型（只追加）

机构需要保存并互相核对以下资料，任何变化都**新增记录**而非改写旧记录：

| 资料 | 内容 |
| --- | --- |
| 法规版本 `rule_versions` | 带生效区间、明确 `retroactive: false`；换版不溯及既往 |
| 产品关系 `products` | 持有人、活性成分、剂型、父子产品（新剂型/新适应症） |
| 研究包与来源 `study_packages` | 境内试验、境外试验、授权引用、公开披露、补充提交；授权引用带授权方、成分范围与有效期 |
| 提交版本 `submissions` | 原始/补充/撤回/转让备案/法院报送，可标记撤回与被接替版本 |
| 权利主张 `claims` | 主张依据（儿童药/罕见病独占期、数据保护）与只追加的状态历史 |
| 法定例外 `legal_exceptions` | 如公共健康强制许可，绑定其所属法规版本 |
| 转让记录 `transfers` | 产品、前后持有人、生效日、备案提交 |
| 法院决定 `court_decisions` | 收窄保护范围（移除适应症）等 |
| 效力区间 `effect_intervals` | 授予/范围扩展/范围收窄/持有人变更/放弃，按 `supersedes` 逐段接替 |
| 申请与核定 `applications` / `determinations` | 三态结论与完整依据；核定只追加，旧结论原样保留 |

**效力区间不变量**（加载时强制校验）：

- 一条主张一条接替链，段与段首尾相接、无分叉无悬空；
- 法定届满日 `term_end` 在授予段按**当时有效规则**计算（首版儿童药 7 年、罕见病 7 年、数据保护 6 年；修订版儿童药 12 年），后续收窄、转让段一律不得改动；
- 撤回只新增 `surrendered` 放弃段，原授予段保留；届满日不因公开披露、转让、法院收窄而变；
- 区间只能覆盖同一活性成分的产品；
- 每条核定记录钉住作出当日有效的法规，依据法规与当日实际生效版本不符即校验失败。

## 核定口径

`evaluate(申请, 决定日)` 完全按决定日的状态回放，结论优先级为：

1. **受理 `accept`**：主张法定例外成立（如强制许可），或无在效阻断（含已放弃、已届满，历史区间整链留作依据）；
2. **暂缓 `suspend`**：存在未裁决的冲突主张（按状态历史回放当日是否仍未决），或授权引用过期/成分范围不符/缺授权依据等待补事项；
3. **等待届满 `wait`**：同一活性成分、同一适应症仍在保护期内，`wait_until` 取阻断区间的法定届满日。

冲突按当日状态成对识别（一方 `conflicting`、另一持有人对抗主张仍 `asserted`），双方主张都进核定依据，审评人员可复核。申请人视图只披露保护范围（产品、适应症、权利人、届满日、依据法规），不披露研究数据来源明细；审评人员视图给出在效区间、未决冲突与全部区间链。

示例故事线覆盖：罕见病独占期内等待（A-1）、冲突窗口期暂缓→驳回后等待且 D-2 不被改写（A-3）、授权函过期且成分不符的待补暂缓（A-2）、法定例外受理（A-4）、资料撤回后受理但区间留痕（A-7）、规则换版后届满受理（A-5）、修订版新授予 12 年独占期（A-6）、法院收窄+转让后仍按首版 7 年届满（A-8）。

# 药物试验数据保护期核定

核定儿童药和罕见病用药试验数据的保护范围与有效期限。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括药品申请人、审评人员、法规复核人员、数据权利持有人。

资料所依据的领域事实如下：

- 监管部门将推进药品试验数据保护制度落地
- 儿童药品和罕见病用药将建立市场独占期制度
- 制度目标之一是保障企业研发投入

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。

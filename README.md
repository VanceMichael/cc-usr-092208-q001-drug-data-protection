# 药物试验数据保护期核定

核定儿童药和罕见病用药试验数据的保护范围与有效期限，并支持对后来申请按**申请时点**回放处置结论。

## 领域资料

- `contracts/domain.schema.json`：共享资料结构（v2）。
- `fixtures/domain.json`：不含真实个人信息的合成示例，覆盖一个跨 2024–2026 年的完整时序。

参与方：药品申请人、受理人员、审评人员、法规复核人员、授权签发人、数据权利持有人。

## 核心规则

- **时点回放**：一项后来申请应当受理、暂缓还是等待保护期届满，只依据**申请当日**有效的法规版本、效力区间、数据来源核定结论与签批记录计算，不看系统里最新的截止日期。
- **效力区间追加**：撤回资料、持有人变更、法院决定、规则换版都不修改既有记录，只追加新的区间或事件。区间左闭右开、首尾相接，每个区间引用各自当时的核定（determination）。
- **历史不可覆盖**：所有核定与受理复核均为 `frozen_record`；校验器会把每条冻结复核与按申请日重放的结果逐条比对，任何被后来状态改写的历史都会报错。
- **三类处置**：
  - 受理：当日无阻断区间，或申请落入有效法定例外窗口；
  - 暂缓：相关主张处于法院中止（届满日无法计算），或同活性成分上存在他人尚未确认的冲突主张；
  - 等待保护期届满：命中他人 active 独占期。中止（suspended）期间不计时，恢复后续算、届满日顺延。
- **双视图**：
  - 申请人视图只含可披露的保护状态/预测届满日与本方待补事项，隐去他方研究包、数据来源编号与授权链内部编号；
  - 审评人员视图列出同一活性成分上相互冲突的主张及各自核定依据，供复核。
- **数据来源分类**：自有数据、授权引用（挂授权链及生效/撤销日期）、公开披露、补充提交，分别登记、分别引用。

## 示例时序

同一活性成分「示例酸A」上：P-101 儿童药片剂（2024 年起 1826 天独占期，含一次突发公共卫生事件例外窗口）；P-102 同成分注射剂（2025 年起 2557 天孤儿药独占期，经历法院中止 92 天→恢复续算→2026 年规则换版另开区间）；P-201 为乙公司成人适应症产品，其主张因授权链覆盖范围与同成分关系待补而未确认，与 P-102 构成冲突主张。六笔后来申请分别落在无主张、active、例外窗口、法院中止、恢复后、新版法规等不同时点。

## 本地校验

```bash
python3 -m unittest discover -s tests
```

- `src/domain.py`：基础资料读取与字段完整性检查。
- `src/protection.py`：时点法规查询、区间定位、届满日预测（含中止顺延）、申请回放、冻结历史比对、双视图与引用完整性/区间连续性校验。
- `tests/`：21 项测试，覆盖三分类、时点法规、事件只追加新区间、历史决定不被覆盖、篡改检出、双视图脱敏与数据来源分类。

仓库不保存账号、密钥、连接串或真实身份信息；示例中的人员、公司、文号均为虚构。
